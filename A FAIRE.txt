E - BUG DE CODE DECOUVERT PENDANT LA REVUE, non corrige
  Le suffixe de qualite "(Q)" est ecrit de deux facons dans DATABASE : 40 items collent le suffixe
  au code ("RULES-ARMO_14(Q)") et 42 mettent un ESPACE avant ("RULES-COMB_2M_05 (Q)").
  Or winlivre.pas LibelleEquipement enleve les 3 derniers caracteres (Copy(CodeItem, 1,
  Length(CodeItem)-Length(EquipementQualite))) sans Trim ensuite, et pdfmetier.pas /
  xmlexportimport.pas coupent avec ExtractStringBefore, ce qui laisse aussi l'espace.
  Le code passe ensuite dans ChercheArme -> CompareRechercheValeur, qui compare sans Trim.
  Consequence attendue : pour les 42 items ecrits avec un espace, le libelle n'est pas retrouve et
  c'est le CODE BRUT qui s'affiche ("RULES-COMB_2M_05 de qualite" au lieu de "Zweihaender de
  qualite"). A verifier par Nono dans WinLivre / WinMetier sur le Greatsword Sergeant.
  Deux corrections possibles : un Trim dans le code, ou normaliser les 42 items du XML.
